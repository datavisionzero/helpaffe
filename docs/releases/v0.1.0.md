# helpaffe 0.1.0

The first self-hosted release provides a central helpdesk for multiple
products. It includes the Web backoffice, a product-facing HTTP API and
server-side .NET SDK, and a noninteractive agent CLI. Project-scoped roles and
credentials, the ticket workflow, search, customer history, support
instructions, project email templates, durable SMTP delivery, and retry are
implemented. The release also includes ticket snoozing, development-task
references, an internal solutions collection, and secure attachments.

The application image is `ghcr.io/datavisionzero/helpaffe:0.1.0` for
`linux/amd64` and `linux/arm64`. This release carries matching CLI archives
and checksums. Install with the two files in
[`deploy/`](https://github.com/datavisionzero/helpaffe/tree/v0.1.0/deploy);
see the [installation guide](https://github.com/datavisionzero/helpaffe/blob/v0.1.0/docs/install.md).

This is a `0.x` release. The example product's user header is a placeholder,
not production authentication. Grouping related customer tickets and accepting
customer replies by email remain later-roadmap work. Back up PostgreSQL and
attachment storage, and retain the SMTP encryption key before upgrading.
