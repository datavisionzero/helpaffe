# helpaffe 0.1.2

This release refreshes the Web backoffice with a compact, responsive application
shell. Ticket work, solutions, administration, credentials, and email settings
now share a clearer visual hierarchy and make better use of available space.

The interface follows the system color scheme by default and adds saved light
and dark appearance choices. On smaller screens, the primary navigation moves
into an accessible menu with keyboard focus handling and Escape-key support.

The application image is `ghcr.io/datavisionzero/helpaffe:0.1.2` for
`linux/amd64` and `linux/arm64`. Matching CLI archives and checksums are
included. Install with the two files in
[`deploy/`](https://github.com/datavisionzero/helpaffe/tree/v0.1.2/deploy);
see the [installation guide](https://github.com/datavisionzero/helpaffe/blob/v0.1.2/docs/install.md).

Existing installations can upgrade without database changes. Back up PostgreSQL
and attachment storage, and retain the SMTP encryption key before upgrading.
