# helpaffe 0.1.1

This release adds optional delivery of API and notification worker logs to a
logaffe installation through `Logaffe.Extensions.Logging`. JSON console logs
remain available. Set `HELPAFFE_LOGAFFE_URL` and `HELPAFFE_LOGAFFE_TOKEN`
together to enable delivery; an incomplete or invalid configuration fails at
startup. The token is a secret and selects the logaffe project.

The application image is `ghcr.io/datavisionzero/helpaffe:0.1.1` for
`linux/amd64` and `linux/arm64`. Matching CLI archives and checksums are
included. Install with the two files in
[`deploy/`](https://github.com/datavisionzero/helpaffe/tree/v0.1.1/deploy);
see the [installation guide](https://github.com/datavisionzero/helpaffe/blob/v0.1.1/docs/install.md).

Existing installations can upgrade without database changes. Back up PostgreSQL
and attachment storage, and retain the SMTP encryption key before upgrading.
